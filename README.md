# 🎮 Rust Launcher Pro

A beautiful and powerful Rust game launcher with Steam integration and performance optimization.

## ✨ Features

- 🎯 **One-Click Launch** - Launch Rust from Steam
- 🚀 **Performance Boost** - FPS optimization
- 🎨 **Beautiful UI** - Modern dark theme
- ⚙️ **Advanced Settings** - Graphics control
- 📊 **Real-time Monitoring** - Performance stats
- 💾 **Save Profiles** - Multiple configurations
- 🌙 **Dark Theme** - Eye-friendly design

## 🛠️ Tech Stack

- React 18 + TypeScript
- Tailwind CSS
- Electron
- Vite

## 📦 Installation

```bash
git clone https://github.com/RCM101/Rust.Launcher.git
cd Rust.Launcher
npm install
npm run dev
```
